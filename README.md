# 雲端藥歷整理小幫手（MedCloud 工作台整合版）

把健保醫療資訊雲端查詢系統的**用藥、檢驗、影像及病理、手術、出院病摘與過敏紀錄**整理成看診當下可核對、可貼入病歷的摘要與表格。

## 安裝（一次就好）

1. 解壓縮後，在 Edge 網址列輸入 `edge://extensions`
2. 左側打開「**開發人員模式**」
3. 按「**載入解壓縮**」
4. 選擇壓縮包內的 `extension` 資料夾

Chrome 也可在 `chrome://extensions` 用相同方式安裝。

裝好後，只要進到 `medcloud2.nhi.gov.tw`，右下角就會出現綠色整理按鈕。

## 用法

1. 先完成健保雲端查詢；各表格若有分頁，請切成顯示全部並核對總筆數。
2. 回到「摘要」頁，按右下角「彙整病歷」。
3. 擴充功能會依序切換六個頁籤，在本機讀取資料，完成後回到摘要頁。
4. 核對六區狀態與預覽，再按「複製完整病歷摘要」貼入授權的病歷系統。
5. 近三個月採曆月計算（例如 8 月 16 日回推至 5 月 16 日，起訖皆包含）；手術、出院病摘與過敏紀錄依原頁查詢範圍。

原本的單頁功能仍保留：在西醫用藥、檢驗或影像及病理頁，可分別按「整理藥歷」、「整理檢驗」或「整理影像／病理」。

## 它做了什麼

- **推估仍在服用**：用「就醫日期＋給藥日數」推算尚未結束的品項，依 ATC3 藥理分類分組
- **續領合併**：同院所、同一支藥的多次處方合併成一項，顯示「已開 N 次、最早某日」
  （不合併的話會嚴重高估用藥種類——實測 12 筆處方其實只有 8 種藥）
- **疑似重複用藥**：同一成分（ATC7）由**不同院所**開立且給藥期間重疊 → 橘色警示
- **高齡者宜注意用藥**：沿用系統原本的標記
- **就醫主診斷彙整**：自動補回 ICD 碼的小數點（健保資料是 B9681，還原成 B96.81）
- **開立院所統計**
- **用藥時序**：每次開立以甘特圖與文字序列呈現，標示跨院所及 14 天以上空窗
- **院所檢視**：門診／住院等開立端與藥局調劑紀錄分段顯示
- **精簡藥歷複製**：依日期由新到舊輸出一行式處方，藥品使用成分名稱（學名）；六區整合摘要的藥歷區塊同步套用，院所與藥局合併為單一時序
- **檢驗時序表**：依日期橫向排列，顯示單位、參考值與迷你趨勢圖
- **異常值摘要**：最新異常與「曾異常、最新已無異常旗標」分開呈現
- **Excel／病歷複製**：檢驗可複製 TSV 大表格、日期／院所簡易條列或完整時序條列
- **影像／病理報告表格**：逐筆讀取原頁報告，排除只有「影像查詢」而沒有報告結果的列，只保留指定五欄；同時提供 HTML 表格與 TSV，可貼入 Word／Excel
- **六區整合病歷摘要**：一次彙整近三個月精簡藥歷、檢驗條列、影像病理表格，以及原頁範圍的手術、出院病摘與過敏紀錄
- **過敏藥物去重**：優先依藥品代碼合併；沒有代碼時才依正規化藥名合併，反應、日期與來源取聯集
- **跨病人保護**：整合前確認頁首病人識別狀態；流程中若指紋改變，或使用者按查詢、登出／送出新查詢表單，會立即清除本次結果
- **工作台整合**：手動下載不含病人識別欄位的結構化藥歷 JSON，可與工作台的診斷、檢驗、影像及出院病摘合併

## 刻意的限制（改動前請先想清楚）

- **完全不連外**：整支程式沒有 fetch／XHR／WebSocket，manifest 的 `permissions` 是空的。
  病人資料只在該分頁記憶體處理，**不寫 localStorage、不寫 chrome.storage、不上傳任何地方**。
- **原頁處理**：不改頁面資料、不代按查詢；整合功能只會依序切換既有頁籤，並逐筆觸發原頁的「報告」或「開啟此筆病摘」按鈕以讀取內容。
- **看得到才整理**：頁面上沒查出來的資料，這支也不會去要。
- **換個案即清除**：單頁面板在表格內容改變時關閉；整合流程偵測病人識別指紋改變時立即中止並清除結果。
- **剪貼簿注意**：複製結果可能進入 Windows 剪貼簿歷程；貼入授權系統後請依院內規範清除。

## 已知限制

- 整合摘要支援西醫用藥、檢驗結果、影像及病理、手術紀錄、出院病摘與過敏紀錄；欄位無法辨識時會標示需回原頁核對，不會猜測內容。
- 過敏紀錄空白不代表 NKDA；仍須核對原頁與問診。
- 「仍在服用」是依給藥日數推估，**不等於病人真的還在吃**，實際仍須問診確認。
- 給藥有效期採「就醫日為第 1 天」計算；未來日期處方不會列為仍在服用。
- 整理與 JSON 只包含頁面當時已載入的表格列；如健保頁面有分頁，使用前請核對總筆數。
- 重複用藥警示僅以開立端 ATC7 為確證條件；藥局調劑不列入。所有警示仍須核對健保原頁與病人實際用藥。
- 同名檢驗若單位、檢體、方法或參考值不同會分列，避免把不可直接比較的結果畫成同一趨勢。
- 若健保署改版調整欄位名稱，解析可能失效；程式是以欄位**標題文字**定位（不是欄位順序），
  所以小改版通常仍可運作，但大改版需要更新。
